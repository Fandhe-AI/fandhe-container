# 日本語出力スタイル

## 基本

- ユーザーとのやりとり・報告・計画・コミットメッセージ本文・ドキュメントはすべて日本語で行う
- 技術用語・コード識別子・コマンドは原語（英語）のまま使う（例: workspace, trait, `cargo test`）

## 表記

- 和文と英単語の間は既存文書（README.md）の流儀に合わせ、半角スペースで区切る
- 箇条書き・表を活用し、冗長な前置きを避ける
- 見出しは名詞止めまたは体言止めを基本とする

## コード内

- コード内コメント・ドキュメンテーションコメントも日本語で書く（[code-comment-style](./code-comment-style.md)）
- エラーメッセージ・ログ・CLI 出力・API レスポンスなどプログラムの出力文字列は英語とする（OCI / CRI / MCP 等のツール連携・AI への入力効率のため）

## コミット・PR

- コミットメッセージ: type/scope は Conventional Commits の英語規約、説明文は日本語（例: `feat(io): フラッシュバリアの FLUSH ACK を実装`）
- PR タイトル・本文も同様の形式とする
